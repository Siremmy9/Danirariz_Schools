HERO VIDEO
==========
school-hero.mp4 in this folder is a tiny animated PLACEHOLDER so the hero works out of the box.
Replace it with your real school video, keeping the same name (or change "heroVideo" in js/config.js).
Tips: MP4 (H.264), 1920x1080 or 1280x720, 10-20 seconds, no audio, under 8 MB, compressed.
If the file is missing or fails to load, the website shows the hero image (heroPoster) instead.
